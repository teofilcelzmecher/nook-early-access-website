# Budgie

A community app built on Material 3 Expressive. Early access: you need an invite code to get in.

Plain HTML, CSS and JS with no build step, and a small Node server in `server/` (see server/README.md). Nothing is loaded from other companies.

See [Terms of Use](terms.html) and [Privacy Policy](privacy.html).
