# Budgie

A community app built on Material 3 Expressive, with nests (communities), posts, comments, friends and chats.

Plain HTML, CSS and JS with no build step, and a small Node server in `server/` (see server/README.md). The only code from another company is Google AdSense, for ads between posts, and only once it is switched on in js/config.js.

See [Terms of Use](terms.html) and [Privacy Policy](privacy.html).
