# Budgie

A community app built on Material 3 Expressive, with nests (communities), posts, comments, friends, chats and calls, in six languages.

Plain HTML, CSS and JS with no build step, and a small Node server in `server/` (see server/README.md). The only code from other companies is Google AdSense (ads between posts, once switched on in js/config.js), Cloudflare Turnstile on the sign-up form, and GIFs from KLIPY, each only once the owner switches it on.
